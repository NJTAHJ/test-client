# 🌐 Cloud Browser in GitHub Codespaces

Run a full, private Chromium browser inside GitHub Codespaces with Discord, Instagram, and TikTok pre-opened.

### 🚀 1-Click Launch
Click the badge below to start your own free cloud browser instance:

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/NJTAHJ/test-client)

---

### 📖 How to Use:
1. Click the **Open in GitHub Codespaces** button above.
2. Wait ~45 seconds for Codespaces to finish building.
3. Switch to the **Ports** tab at the bottom of the editor.
4. Click the **Globe icon (Open in Browser)** next to **Port 3000**.
5. Your cloud browser will open with Discord, Instagram, and TikTok ready to go.
